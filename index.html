Bot WhatsApp Core

Skrip utama untuk menjalankan automasi chat dan sistem checkout ritel.

1. Inisialisasi Koneksi

Gunakan skrip ini untuk menghubungkan bot menggunakan library Baileys.


const { default: makeWASocket, useMultiFileAuthState } = require('@whiskeysockets/baileys');

async function startIndcBot() {
    const { state, saveCreds } = await useMultiFileAuthState('./auth_info');
    
    const sock = makeWASocket({
        printQRInTerminal: true,
        auth: state,
        browser: ["INDC PROJECT", "Chrome", "1.0.0"]
    });

    sock.ev.on('creds.update', saveCreds);
    
    sock.ev.on('connection.update', (update) => {
        const { connection, lastDisconnect } = update;
        if (connection === 'close') {
            console.log('Koneksi terputus, mencoba ulang...');
            startIndcBot();
        } else if (connection === 'open') {
            console.log('Bot INDC siap digunakan!');
        }
    });
}

startIndcBot();

Scraper PLU Barang

Skrip untuk mengambil data harga dan nama barang berdasarkan PLU (Price Look-Up).

Fungsi Pencarian

Integrasikan fungsi ini dengan endpoint API internal toko.


async function cariDataBarang(plu) {
    try {
        console.log(`[INDC] Memulai pencarian untuk PLU: ${plu}`);
        const response = await fetch(`https://api.internal-toko.com/v1/product/${plu}`);
        
        if (!response.ok) throw new Error('Data tidak ditemukan');
        
        const data = await response.json();
        return {
            sukses: true,
            nama: data.product_name,
            harga: data.price,
            rak: data.planogram_id
        };
    } catch (error) {
        return { sukses: false, pesan: error.message };
    }
}

Jalankan perintah ini di terminal SSH Armbian Anda (Root Access).


# 1. Update sistem operasi
apt update && apt upgrade -y

# 2. Instalasi CasaOS dengan satu baris perintah
curl -fsSL https://get.casaos.io | sudo bash

# 3. Cek status docker setelah instalasi selesai
systemctl status docker
